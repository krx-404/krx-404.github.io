# 06 — Outils du quotidien (junior)

Un junior n’a pas besoin de 300 tools. Il a besoin d’un **kit propre**.

## Kit de base

| Catégorie | Outils | Usage |
|-----------|--------|-------|
| OS | Parrot / Kali / Debian | Environnement |
| Proxy | Burp Suite / ZAP | Intercepter le web |
| Recon web | browser + DevTools | Comprendre l’app |
| Réseau | Wireshark, nmap | Voir / cartographier (scope autorisé) |
| Notes | Obsidian / Notion / Markdown | Mémoire longue |
| Report | Markdown / PDF | Livrable |

## Bonnes pratiques outils

- Apprends **un outil à fond** avant d’en ajouter dix
- Garde des notes de commandes utiles
- Sépare lab / perso / pro (VMs)
- Ne colle jamais de secrets dans un repo public

## Ce que je veux éviter

- Tool hopping (changer d’outil chaque jour)
- Screenshots sans explication
- “Automatiser” avant de comprendre manuellement

## Checklist étape 06

- [ ] Burp/ZAP OK sur un lab local
- [ ] Système de notes en place
- [ ] Je sais exporter un mini rapport propre
