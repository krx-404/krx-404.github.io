# 05 — Labs & CTF (la vraie progression)

La théorie sans labs = illusion.  
Les labs sans notes = progrès qui disparaît.

## Ma règle

> **1 lab fini = 1 write-up** (même court)

Template : [`../templates/WRITEUP.md`](../templates/WRITEUP.md)

## Plateformes utiles

- **TryHackMe** — guidé, parfait débutant → junior
- **Hack The Box** — plus rough, bon après les bases
- **PortSwigger Academy** — référence sécurité web
- **picoCTF / CTF locaux** — culture challenge

## Comment progresser sans se noyer

1. Choisis une room / lab adaptée à ton niveau
2. Chronomètre pas ta valeur : comprends
3. Bloqué 30–45 min → cherche un hint, pas un full spoil
4. Réécris la solution **avec tes mots**
5. Ajoute “ce que j’ai appris” + “ce que je referai mieux”
